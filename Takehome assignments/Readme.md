## Rectangle (`RECTANGLE.cpp`)

`RECTANGLE.cpp` defines a `Rectangle` class that stores a rectangle's width and
length. The dimensions are private and are set through public setter methods.
The class provides methods to calculate the area and perimeter.

### Calculations

- **Area:** `width * length`
- **Perimeter:** `2 * (width + length)`

The program creates a rectangle with a width of `5.5` and a length of `10.0`,
then prints its dimensions, area, and perimeter.


Expected output:

```text
Rectangle Dimensions: 5.5 x 10.0
Area: 55
Perimeter: 31
```
